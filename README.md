# 🎉 EventPro - Event Management System

A web-based Event Management System developed using Django for managing event services, public events, bookings, and registrations.

---

## 📌 Features

### User Module
- User Registration & Login
- Edit Profile
- Book Event Management Services
- Register for Public Events
- Download Event Tickets
- View Booking History
- View Event Registrations

### Admin Module
- Manage Services
- Manage Public Events
- Approve/Cancel Service Bookings
- View Event Registrations
- View Contact Messages
- Dashboard Statistics

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/EventPro.git
```

Go inside the project

```bash
cd EventPro
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Install Requirements

```bash
pip install -r requirements.txt
```

Run Migrations

```bash
python manage.py migrate
```

Start Server

```bash
python manage.py runserver
```

Open

```
http://127.0.0.1:8000/
```
